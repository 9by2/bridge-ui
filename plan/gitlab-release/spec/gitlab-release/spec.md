# GitLab Release Contract

`bun coverage:runtime` measures `app/**/*.{ts,tsx}` and `shared/**/*.{ts,tsx}` with a 90% statement, branch, function and line floor. Generated `app/component/shadcn/**` and the export-only `app/index.ts` barrel are excluded. Brand component retains 100% coverage. Hook code remains in scope. Generated component still requires catalog, accessibility and integration verification. Command and catalog are verified separately by mandatory source and catalog CI jobs, including Bun test, boundary, packed client/SSR, tree-shaking and Playwright verification. This is not repository-wide numerical coverage. Any required gate failure blocks publication.

Every branch/MR/tag pipeline runs strict validation. Deployment is manual and only on a protected prerelease tag whose version equals package.json; npm tag is next, never latest. Publish authentication uses CI_JOB_TOKEN and project-local endpoint. Installed registry package must resolve after publication. No credential is committed or retained as an artifact. Actual runner/registry proof remains pending.
