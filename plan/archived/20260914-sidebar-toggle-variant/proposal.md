# Proposal: Sidebar Toggle Variant

## Problem

The side/variant catalog example uses the default offcanvas collapse mode. Toggling removes every sidebar surface, so the catalog no longer demonstrates the visual difference between sidebar, floating, and inset.

## Scope

- Keep each side/variant sidebar visible as an icon rail after toggle.
- Verify expanded and collapsed geometry for every side/variant combination.
- Capture collapsed browser evidence.

## Out Of Scope

- Public Sidebar API change.
- Offcanvas and persistent collapse example change.

## Success

- Every side/variant example uses icon collapse.
- Toggle verification proves the sidebar remains visible.
- Sidebar, floating, and inset remain visually and geometrically distinct after toggle.
