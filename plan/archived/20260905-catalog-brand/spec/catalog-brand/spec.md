# Catalog Brand Contract

**Status:** accepted

Custom presentation lives in app/component/brand. Catalog exposes upstream chart inventory and explicit inline UI variation with usable interaction. Generated source is changed only through CLI. DropArea accepts application-owned copy and callback, not upload business logic.

TsChart forwards SVG, tooltip-body and explicit renderer prop. The catalog snapshots 188 upstream v0.16.0 entries with licensed data, exact entry source and supporting source disclosure. Near-viewport mounting bounds runtime and resets offscreen transient state. MultiSelectValue applies default badge appearance through the stable public export. Empty has icon, dotted and muted compositions; menu/navigation has multiple choice; conversation shows both alignment; pagination has borderless selection; Sonner exposes callable feedback.
