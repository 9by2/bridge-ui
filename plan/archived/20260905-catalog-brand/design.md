# Design

Keep generated source untouched. Brand owns custom presentation. Catalog example remains executable with inspectable source. Inventory and browser checks cover requested behavior; record upstream compatibility limitations rather than claiming unsupported coverage.

Use versioned upstream source and private dataset as a local development dependency. Near-viewport iframe mounting bounds chart runtime on a 190-example page; offscreen state resets explicitly. Static browser verification avoids Vite dependency-discovery reload. Upstream palette-specific demo retains its own theme; Bridge primitive source is not silently restyled to pass contrast.

```tsx
import { TsChart, DropArea } from "@bridge/ui"
```
