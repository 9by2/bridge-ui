# Decision

**GIVEN** custom component needs a distinct home
**WHEN** maintaining TsChart and DropArea
**THEN** use app/component/brand, preserving stable public export.

**GIVEN** the upstream catalog has 188 independent example and private demo data
**WHEN** covering the full inventory
**THEN** vendor the versioned MIT source closure and dataset attribution as development-only source; route Chart and RendererChart through TsChart.

**GIVEN** a development server can reload during lazy dependency discovery
**WHEN** verifying the full catalog
**THEN** test an isolated static build on port 6007 rather than share the developer server on 6006.

**GIVEN** MultiSelect is preserved generated source
**WHEN** applying the requested default badge treatment
**THEN** override the public value export with a thin brand presentation wrapper, without editing the generated file.
