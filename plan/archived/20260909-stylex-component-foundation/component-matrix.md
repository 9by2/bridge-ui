# Complete Component Usecase And Gap Matrix

Inventory at local `7150c06`: **70 component modules**, 63 generated + 7 owned. One row per `.tsx` module under `app/component/`; compound slot and exported hook stay within the owning row. `global/` is empty. This is an implementation matrix, not certification of every component state. Proposed Theme would be a new module and is not counted as existing.

## Reading Key

- **E**: number of local catalog example files, not interaction-test count or coverage percentage. MultiSelectValue is exercised through the multi-select example rather than its own page.
- **W1**: bounded pilot. **W2**: simple presentation and form. **W3**: overlay/selection/provider. **W4**: layout/navigation/conversation. **W5**: chart/upload/complex adapter. A wave is a dependency stage, not a schedule promise.
- **Owned port**: new `app/component/brand/<name>.tsx` over the same engine/native element, leaving generated source untouched. Use the design's export-promotion process only after approval.
- **Local slot**: apply StyleX to an element owned by the package. **Engine slot**: use a documented third-party component/className/style/render hook. **Adapter**: narrowly scoped CSS only if the engine does not expose the required slot; record the exception.
- Every row inherits the common acceptance contract: prop/ref/ARIA identity, no hydration recovery, keyboard where interactive, disabled/invalid/loading/open/empty as applicable, long/Thai copy, light/dark, 390/1280, reduced motion, RTL where relevant, no host CSS leakage and lifecycle cleanup. Explicitly mark genuinely inapplicable state rather than pretending it was tested.
