# Spec: Coverage and Test Gates

**Spec ID:** `coverage-and-test-gates`
**Proposal:** `coverage-and-test-gates`
**Status:** accepted

## Requirements

### REQ-001: Runtime coverage

Owned runtime source remains included in coverage and meets configured thresholds through public behavior contracts.

### REQ-002: Test gate integrity

The full unit and catalog suites pass without disabling or weakening assertions unrelated to the repaired defect.
