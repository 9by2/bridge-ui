# Design

The package and catalog compile package-owned StyleX through the same compiler and publish precompiled JavaScript plus one CSS entry. Generated Shadcn source remains CLI-owned reference source; supported public presentation paths resolve to owned StyleX implementation. A consumer requires no Tailwind or StyleX transform.

```tsx
import { DropArea } from "@bridge/ui/drop-area"
import "@bridge/ui/style.css"
```

Release automation has proven private registry RC and stable publication, isolated package installation, and Git tag creation. The remaining release gate is consumer evidence: install the exact current registry artifact in the bounded Bridge Web fixture, run the matching-chart probe, and reconcile every ADHD foundation requirement before approving migration.
