# GitLab Release Contract

`bun coverage:runtime` measures `app/**/*.{ts,tsx}` and `shared/**/*.{ts,tsx}` with a 90% statement, branch, function and line floor. Generated `app/component/shadcn/**` and the export-only `app/index.ts` barrel are excluded. Brand component retains 100% coverage. Hook code remains in scope. Generated component still requires catalog, accessibility and integration verification. CI keeps mandatory Bun test, boundary, exhaustive static catalog build, packed client/SSR and tree-shaking verification. Compact Bun.WebView contracts remain a required local pre-push gate; visual and memory diagnostics run for relevant changes and release verification. This is not repository-wide numerical coverage. Any required gate failure blocks its owning workflow.

Every branch/MR/tag pipeline runs strict validation. Release follows the accepted Changesets release MR contract in `plan/spec/changeset-release/spec.md`: protected default-branch automation after verification, RC under next and stable under latest, Git tag after publication. Publish authentication uses CI_JOB_TOKEN and project-local endpoint; GITLAB_TOKEN maintains branch/MR/tag. Installed registry package must resolve after publication. No credential is committed or retained as an artifact. Bot, runner, registry install, stable publication, and Git tag creation are proven by the published 0.2.0, 0.3.0, and 0.4.0 release history.

The release MR's own pipeline (`changeset-release/main`, a `merge_request_event`) still runs full `source`/`coverage`/`catalog` verification before merge is allowed — this contract is unchanged. Per `plan/spec/release-fast-path/spec.md`, once that MR is squash-merged into protected `main` with the fixed automation commit title (`chore: version package` or `chore: version package (rc)`), the resulting protected-main push pipeline skips the redundant `source` and `coverage` jobs (version-only diff already verified pre-merge) and proceeds directly to the `release` job, which keeps its existing protected-branch gate unchanged.
