# Spec: Setting Item Icon Actions

**Spec ID:** `setting-item-icon-actions`
**Proposal:** `setting-item-icon-actions`
**Status:** accepted

## Summary

Defines accessible edit icon-button examples for inline account settings in both relevant catalogs.

## Requirements

### REQ-001: Accessible edit icon

Both `SettingItem` and `Settings` catalog examples SHALL render a ghost icon-size edit button with a `PencilIcon` and an accessible name that identifies the setting.

**Acceptance:**

- [ ] Each icon action has an accessible name.
- [ ] The icon is decorative to assistive technology.

## Non-Goals

- Editing state or new component API.
