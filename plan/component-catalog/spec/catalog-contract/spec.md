# Catalog Contract

**Status:** accepted

- `bun dev` opens the complete searchable component catalog.
- Every generated module has a real package-root example with exact copyable source.
- Preview is isolated from the shell. Theme, locale caption, reduced motion and viewport remain selectable.
- Example selection and comparison are available without a testing panel.
- Browser verification includes every retained example, accessibility and the ten existing core interaction families.
- Static catalog build and package verification must pass before removing Storybook.
- Full interactive, state, visual and numerical coverage remain foundation requirements; this replacement does not waive them.
